# Hermes Project Identity

## What is Hermes?

Hermes is a persistent AI brain designed to preserve understanding, memory, learning, reflection, and evolution across model changes. It treats knowledge as a living artifact: detected from raw observations, validated against completeness and confidence rules, persisted as versioned knowledge, and continuously refined through planning, execution, learning, reflection, and evolution cycles.

## Core Identity

- **Name**: Hermes Brain
- **Type**: Persistent AI cognitive architecture
- **Purpose**: Preserve and evolve understanding across model generations
- **Architecture**: Constitutional, domain-driven, pure layered architecture
- **Maturity**: Architecture complete, certified, frozen

## What Hermes Is NOT

- A chatbot or conversational agent
- A retrieval-augmented generation (RAG) system
- A vector database with embeddings
- A prompt engineering framework
- A traditional machine learning pipeline

---

## Architectural Lineage

Hermes is built on constitutional architecture principles:

1. **Strict layer separation** — Domain, Engines, Application, Infrastructure, Runtime
2. **Pure domain layer** — Zero external dependencies, frozen dataclasses
3. **Constitutional pipeline** — 8-stage cognitive pipeline with explicit boundaries
4. **Traceability** — Every execution traces back to originating observation
4. **Immutability** — All domain models frozen; history append-only
5. **Explicit contracts** — Every boundary has explicit contracts

## Key Differentiators

| Traditional AI Systems | Hermes |
|------------------------|--------|
| Stateless per session | Persistent across sessions |
| Knowledge as embeddings | Knowledge as versioned, validated artifacts |
| Implicit reasoning | Explicit constitutional pipeline |
| Black-box inference | Traceable, auditable decisions |
| Single-model dependency | Model-agnostic architecture |
| Implicit knowledge | Explicit, traceable knowledge graph |

## Success Criteria

Hermes succeeds when:
1. An AI can resume work after model change with full context
2. Knowledge persists and evolves across model generations
3. Every decision traces to originating evidence
4. Architecture remains stable across implementation phases
5. New cognitive capabilities integrate without architectural redesign
