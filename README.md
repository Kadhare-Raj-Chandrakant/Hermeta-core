# Hermes Brain

A persistent intelligence operating system designed to preserve understanding across language model sessions.

This is not an AI agent. This is not a chatbot. This is not a memory plugin. It is the intelligence layer that sits between users and any language model.

## Operational Status

Hermes Core v1.0.0 — constitutionally governed 8-engine pipeline
(Observation → Hypothesis → Problem → Proposal → Evaluation → Governance → Authorization → Execution),
architecture B.8 frozen.

All engines compute deterministically from input content (no canned stubs):
observation extracts real signal metrics, hypotheses differentiate by evidence
strength, governance and authorization derive states from constraint metadata.
The engines are deterministic analysis scaffolds, not ML models — reasoning depth
is bounded by each engine's deterministic logic, by design (E-12/X-7 determinism law).

1,900 tests pass: architecture boundary enforcement, pipeline determinism,
fault-injection resilience, and runtime constitutional compliance certification.
